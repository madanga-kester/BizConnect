## Asset and pixel limits

The source screenshots are raster acceptance references, not the original design files. Exact original icon glyph geometry, font files/weights, compression artifacts, anti-aliasing, and any pixels embedded in screenshot-only crops cannot be recovered. The implementation therefore uses real inline SVG icons and the supplied local image crops/assets where available; it does not claim the original source assets for pixels that were only recoverable from the screenshots.
